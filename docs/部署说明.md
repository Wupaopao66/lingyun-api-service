## 2. 部署步骤

### 2.1 获取代码
```bash
# 以 root 用户为例
cd /root
git clone <你的仓库地址> API-Service
cd API-Service
```

### 2.2 安装依赖
```bash
npm install
```
必须安装的依赖包已在 `package.json` 中，包含：
- express, body-parser, qrcode, nodemailer, dotenv

### 2.3 配置环境变量
```bash
cp .env.example .env
vi .env
```
**必填项**：
- 微信支付商户号、APIv3密钥、证书序列号（私钥路径已固定为 `./apiclient_key.pem`）
- 企业邮箱授权码（发件人 `lingyun@lingyunai.cn`）
- 域名（默认 `lingyunai.cn`）

### 2.4 确认证书位置
```
项目根目录/
├── apiclient_key.pem      # 微信支付私钥（必须）
├── apiclient_cert.pem     # 微信支付证书（可选）
├── pub_key.pem            # 平台公钥（可选）
└── ssl/
    ├── lingyunai.cn.key        # SSL私钥
    └── lingyunai.cn_bundle.crt # SSL证书链
```

### 2.5 启动服务
```bash
# 开发测试
node app.js

# 生产推荐使用 pm2
pm2 start app.js --name lingyun-pay
pm2 save
pm2 startup
```

### 2.6 Nginx 反向代理（可选）
若需通过 Nginx 转发，配置示例：
```nginx
server {
    listen 80;
    server_name lingyunai.cn;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name lingyunai.cn;

    ssl_certificate     /root/API-Service/ssl/lingyunai.cn_bundle.crt;
    ssl_certificate_key /root/API-Service/ssl/lingyunai.cn.key;

    location / {
        proxy_pass https://127.0.0.1:443;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
**注意**：本服务已直接监听443端口，若使用 Nginx 需修改 `app.js` 端口或关闭 Nginx SSL 模块。
