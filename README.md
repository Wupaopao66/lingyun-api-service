## 🚀 快速接入

### 1. 获取API Key
前往官网注册：https://lingyunai.cn

### 2. 调用示例（JavaScript）
```javascript
const apiKey = "你的API密钥";
const baseUrl = "https://lingyunai.cn/api/rate";

const params = { from: "USD", to: "CNY" };

fetch(`${baseUrl}?${new URLSearchParams(params)}`, {
  method: "GET",
  headers: { "x-api-key": apiKey }
})
.then(res => res.json())
.then(data => console.log("实时汇率：", data))
.catch(err => console.error("请求失败：", err));
```
